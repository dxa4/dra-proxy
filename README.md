# X5 Copilot Proxy

Локальный прокси-сервер для работы с X5 Copilot API из Figma-плагина.

## Зачем это нужно

Figma-плагины не могут обращаться к корпоративному X5 API напрямую из-за ограничений CORS. Этот прокси запускается локально на твоём компьютере и решает эту проблему.

---

## Установка и запуск

### macOS (M1/M2/M3)

1. Скачай файл `x5-proxy-macos-arm64` со страницы [Releases](../../releases/latest)
2. Открой **Терминал** (`Cmd+Space` → «Терминал»)
3. Выполни команды:

```bash
chmod +x ~/Downloads/x5-proxy-macos-arm64
~/Downloads/x5-proxy-macos-arm64
```

> Если файл лежит не в Downloads, замени путь. Например, для рабочего стола:
> ```bash
> chmod +x ~/Desktop/x5-proxy-macos-arm64
> ~/Desktop/x5-proxy-macos-arm64
> ```

4. Убедись что видишь в терминале:
```
✅ Прокси запущен: http://localhost:3000/
```

---

### Windows

1. Скачай файл `x5-proxy-win.exe` со страницы [Releases](../../releases/latest)
2. Дважды кликни на файл
3. Если появилось предупреждение SmartScreen — нажми **«Подробнее» → «Выполнить всё равно»**
4. Убедись что видишь в окне терминала:
```
✅ Прокси запущен: http://localhost:3000/
```

---

## Настройка плагина

После запуска прокси:

1. Открой плагин в Figma
2. Перейди в настройки
3. Введи свой API-ключ (скопируй его с этой страницы https://copilot.x5.ru/copilot-api)
4. Нажми **Сохранить**

API URL и модель уже прописаны автоматически.

---

## Важно

- Прокси работает только пока открыто окно терминала — не закрывай его во время работы с плагином
- Требуется подключение к корпоративному VPN X5
- Порт: `3000` — убедись что он не занят другим приложением
